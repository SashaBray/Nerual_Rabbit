# План: хронологический порядок годов в матрице

Статус: **НЕ СДЕЛАНО** (дорожная карта). На текущие модели не влияет (сеть учится при любом порядке),
но нужно для интерпретируемости: строка матрицы как график должна читаться слева→направо = от старого
года к новому.

## Проблема

Сейчас матрица примера собирается с `concat_newest_first = true`, и
`_block_years(target_year, n, newest_first=True)` даёт порядок блоков:

```
[ target_year , target_year-1 , target_year-2 ]   # НОВЕЙШИЙ слева
```

То есть первый 365-дневный блок = прогнозируемый (целевой) год, прошлые годы — справа. Если вывести
строку признака как график, история идёт «задом наперёд».

## Цель

Порядок блоков — ХРОНОЛОГИЧЕСКИЙ (старый → новый, слева → направо):

```
[ target_year-2 , target_year-1 , target_year ]   # ЦЕЛЕВОЙ год СПРАВА (последний блок)
```

Тогда `plt.plot(matrix_row)` показывает естественную историю временного ряда.
