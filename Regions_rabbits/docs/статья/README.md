# Статья: материалы

Всё, что относится к готовящейся публикации о нейросетях проекта. Рабочие документы самого
проекта (журнал моделей, планы по данным) лежат уровнем выше, в `docs/`.

| Файл | Что внутри |
|---|---|
| [Замечания_к_статье.md](Замечания_к_статье.md) | что проверить, пересчитать и обязательно оговорить, чтобы цифры выдержали рецензию — десять пунктов |
| [Таблица_моделей_озимая_пшеница.md](Таблица_моделей_озимая_пшеница.md) | состав входа, длительность, веса и точность всех вариантов озимой пшеницы — таблица для статьи |
| [Опыты_честный_сплит.md](Опыты_честный_сплит.md) | протокол и результаты опытов в честной постановке: схема фолдов, эталоны, лесенка утечек, ёмкость — цифры для основного раздела |

Источники чисел во всех документах: метаданные обучения (`workspace/models/*/details.json`),
опыты заблаговременности (`workspace/reports/forecast/*/leadtime.csv`), таблица БД
`model_metrics`. Где данных нет, так и написано.
