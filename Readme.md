# Nerual Rabbit — прогноз урожайности по спутниковым данным

Программа собирает обучающие выборки из спутниковых временных рядов (NDVI, температура,
осадки, влажность, снежный покров, влага в почве — сервис Vega-Science) и данных об
урожайности районов (архив БДПМО, ЕМИСС), обучает на них модели и строит прогноз
урожайности по регионам и районам России.

Прогноз считают четыре модели и их ансамбль: свёрточная нейросеть, случайный лес,
линейная регрессия и классическая экспоненциальная регрессия по максимуму NDVI.
Различия версий моделей и измеренная точность — в
[`Regions_rabbits/docs/Журнал_моделей.md`](Regions_rabbits/docs/Журнал_моделей.md).

## Что в репозитории

| Папка | Что там |
|---|---|
| `Regions_rabbits/code/` | весь рабочий код: оконное приложение, сборка датасетов, обучение, прогноз, отчёты |
| `Regions_rabbits/docs/` | журнал моделей и заметки по устройству данных |
| `Regions_rabbits/installer/`, `make_exe.py`, `nerual_rabbit.spec` | сборка exe и мастера установки |
| `Regions_rabbits/logos/` | логотипы и значки приложения |
| `ComplexPrediction/`, `*.py` в корне | первая версия проекта (курсовая работа, 2024) |

**Данных в репозитории нет.** База, обученные модели и обучающие выборки весят десятки
гигабайт и раздаются отдельно: программа скачивает их по ссылке из вкладки «Каталог»
(см. [`code/assets.py`](Regions_rabbits/code/assets.py)). Ключей доступа в коде тоже нет —
см. «Ключ доступа к Vega» ниже.

## Запуск из исходников

```
pip install -r Regions_rabbits/requirements.txt
python Regions_rabbits/code/app_gui.py
```

При первом запуске программа создаёт рядом с собой папку `workspace` со справочниками и
предлагает скачать готовую базу и модели из каталога.

## Сборка exe и установщика

```
python Regions_rabbits/make_exe.py              # dist/NerualRabbit/ — папка с NerualRabbit.exe
python Regions_rabbits/make_exe.py --installer  # плюс мастер установки (нужен Inno Setup 6)
```

Сборка проверяет, что в дистрибутив не попал ключ доступа, и делает пробный запуск
собранного exe. Программа и её данные живут в одной папке: удалили папку — удалилась и база.

## Устройство

- **Данные** — файловая «база» из CSV/Parquet в `workspace/database/` (`code/db.py`):
  территории, урожайности, нормализованные временные ряды. Таблицы записаны для Excel
  (разделитель `;`), поэтому открываются по столбцам и правятся руками.
- **Сборка выборок** — `code/build_dataset.py`, задания описаны таблицей
  `workspace/tasks/dataset_tasks.csv`: список параметров, длительность в годах, годы,
  окно климатологии и скользящей средней урожайности.
- **Обучение** — `code/train_*.py` (свёрточная сеть на PyTorch), `code/train_sk.py`
  (случайный лес и линейная модель).
- **Прогноз и отчёты** — `code/app_predict.py`, `code/app_reports.py`, выгрузка партии
  прогнозов в папку-артефакт с таблицами и отчётом Word — `code/app_export.py`.
- **Приложение** — `code/app_gui.py` (PySide6): данные об урожайности, ручной ввод
  пропусков, создание прогноза, модели, отчёты, подгрузка данных, каталог.

## Ключ доступа к Vega

Запросы к Vega-Science идут по персональному ключу (`ukey`). **В коде и в сборке его нет**:
программа читает ключ из `workspace/config/ukey.txt` либо из личного кабинета, скрипты
первой версии — из переменных окружения `VEGA_UKEY`, `VEGA_LOGIN`, `VEGA_PASSWORD`.
Ключ выдаётся при регистрации на sci-vega.ru.

Без ключа программа тоже работает: прогноз считается по данным, которые уже есть в базе
(например, по скачанному из каталога полному снимку). Перед расчётом программа показывает,
каких данных не хватает и сколько прогнозов получится сделать.

## Установка

1. Чтобы сделать прогноз продуктивности, необходимо подготовить файл с расчетным заданием.
По умолчанию файл с расчетным заданием находится в директории:

	`Nerual_Rabbit_0:\Destination_files`

и записан под именем `Destination template test.xlx`.
	В данный файл необходимо загрузить список районов и регионов, для которых необходимо
произвести расчеты. Необходимо указать id районов и регионов. Если необходимо сделать расчет
для региона, графу с id района нужно пропустить. В файл рекомендуется ввести таблицу с данными
об урожайностях в прошлые годы. Как минимум 2 значения об урожайности в районе за любые годы.
Оптимально — не менее 4х примеров.
	Необходимо оставить незаполненную колонку под именем модели, которую необходимо
использовать + кодовое слово `_predict_` + год прогноза.
Например: `NN_CN_v7_winter_wheat_predict_2025`.
Список доступных моделей можно посмотреть в директории `Nerual_Rabbit_0:\Service_files\Models`.
	В таблице должна быть заполнена колонка с указанием культуры. Как правило, в одной таблице
предполагается расчитывать одну культуру. Указание культуры важно для выбора масок NDVI.

2. Чтобы программа могла обращаться к сервису Вега-Science, ей необходимо предоставить ukey
для запросов. Ukey задаётся переменной окружения `VEGA_UKEY` (прежде он вписывался в код —
теперь в коде ключей нет). Если у Вас нет своего ukey, вы можете написать письмо на почту
tolpin@d902.iki.rssi.ru и попробовать договориться о регистрации своей учетной записи.
Вы можете запустить расчет в демонстрационном виде без ukey, но тогда программа будет подавать
в нейронную сеть только те временные ряды, которые уже скачаны в директорию
`Nerual_Rabbit_0:\Temporary_information\TimeRows`. Во всех случаях, когда программе не будет
хватать данных, расчеты будут пропущены.

3. Чтобы запустить расчет, необходимо запустить код файла `Nerual_Rabbit_0:\Nerual_Rabbit.py`.

4. После того, как расчет будет завершен, можно открыть файл с заданием и ознакомиться с
результатами. Открывать файл в процессе расчетов не рекомендуется. При необходимости
рекомендуется сделать копию и открыть ее. Чтобы повторить расчеты, необходимо отчистить поля,
которые должны быть заполнены нейросетью.
